Recursos externos + práticas que aceleram sua evolução em paralelo à trilha 42:

🎮
Plataformas de Prática CTF
Pratique exploits reais fora da 42. Use em paralelo com os projetos.
  • pwn.college — melhor para binários/exploits
  • TryHackMe — guiado, ótimo para iniciantes
  • HackTheBox — nível intermediate/hard
  • picoCTF — Carnegie Mellon, gratuito
  • OverTheWire — wargames clássicos Linux
  • Root-Me — muitos desafios em francês
🛠️
Ferramentas Essenciais
Domine estas ferramentas antes e durante os projetos. São o alfabeto do hacker.
  • GDB + pwndbg — debug avançado de binários
  • Radare2 / Ghidra — reverse engineering
  • Burp Suite — interceptar HTTP (web hacking)
  • Wireshark — análise de pacotes de rede
  • Metasploit — framework de exploits
  • pwntools (Python) — automatizar exploits CTF
  • strace / ltrace — trace de syscalls
📚
Leituras Fundamentais
Livros e recursos que separam quem entende de quem apenas executa.
  • Hacking: Art of Exploitation — Jon Erickson
  • The Web Application Hacker's Handbook
  • Computer Security: Art and Science — Matt Bishop
  • Beej's Guide to Network Programming
  • exploit.education — VMs práticas
  • Z0F Reverse Engineering Course
🧠
Mindset & Metodologia
Hacker não é título, é forma de pensar. Treina isso todo dia.
  • Leia writeups de CTFs resolvidos (post-mortem)
  • Mantenha um diário de exploits (Obsidian/Notion)
  • Pratique OSINT em alvos fictícios/legais
  • Siga: LiveOverflow, John Hammond no YouTube
  • Participe de CTFs ao vivo: CTFtime.org
  • Crie seu home lab: Kali + VMs vulneráveis
🔐
Certificações para o Futuro
Após a trilha 42, estas certs provam seu skill no mercado.
  • eJPT — INE, entry-level pentest
  • CEH — EC-Council, reconhecida globalmente
  • OSCP — OffSec, a mais respeitada de pentest
  • CompTIA Security+ — fundamento amplo
  • GREM — GIAC, reverse engineering/malware
  • Após 42: OSCP é o objetivo natural
⚡
Stack C que você PRECISA dominar
A 42 é em C — estes tópicos são pré-requisito silencioso para os projetos crypto/malware.
  • Ponteiros e aritmética de ponteiros (avançado)
  • Gestão de memória: malloc/free/valgrind
  • Bit manipulation: AND, OR, XOR, shifts
  • Endianness (big vs little) — crítico em crypto
  • Inline assembly (x86/x64 basics)
  • Makefile + linking manual
  • System calls: open/read/write/mmap/fork
